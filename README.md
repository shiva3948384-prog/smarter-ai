# Smarter AI Android Application

This repository contains the Smarter AI Android application built with Kotlin and Jetpack Compose.

## Run Locally

**Prerequisites:** [Android Studio](https://developer.android.com/studio)

1. Open Android Studio
2. Select **Open** and choose the directory containing this project
3. Allow Android Studio to sync Gradle dependencies
4. Configure `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `AI_GATEWAY_URL` in `.env` (see `.env.example`)
5. Run the app on an emulator or physical device
